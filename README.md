# Home Dashboard

自宅の壁掛けディスプレイ用ダッシュボード。
公開URL: https://my-home-board.github.io/home-dashboard/

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面のHTML構造だけ |
| `style.css` | デザイン |
| `app.js` | 本体ロジック（時計・表示モード・各データ取得） |
| `config.js` | 設定データ：バス時刻表・祝日・ごみ収集ルール |
| `presence_status.html` | 在宅ステータスの手動切替ページ |
| `cat/` | 猫イラスト画像 |

## 表示モードと在宅判定

- 在宅のときだけ表示する。在宅でない／状態が分からないときは黒画面（`off`）。
- 朝モード 6:00–9:00：バス・通勤状況・今日の予定・今日のごみ
- 夜モード 21:00–24:00：今日の活動量（歩数など）・明日の予定・明日のごみ・明日の天気
- 在宅状態は Cloudflare Worker の `/presence` から取得する。書き込みは iPhone のショートカット（自宅Wi-Fi接続で home、外出で away）が担当。
- 在宅チェックは表示時間付近（5:50–9:00 / 20:50–24:00）のみ1分ごとに実行。それ以外の時間は定期チェックしない。
- 取得に失敗したら、10分以内のキャッシュがあればそれを使い、なければ不在扱い（消灯）。

## データソース

すべて1つの Cloudflare Worker（`home-dashboard-calendar.s6kyll15g.workers.dev`）経由。天気だけ Open-Meteo から直接取得（東京駅の座標）。

| エンドポイント | 内容 | 認証 |
|---|---|---|
| `/calendar` | Googleカレンダーの予定 | Bearerトークン |
| `/transit` | 山手線・京浜東北線・銀座線の運行情報 | Bearerトークン |
| `/bus` | 都バス東43のリアルタイム位置 | Bearerトークン |
| `/health` | Apple Health の歩数・距離・活動エネルギー | Bearerトークン |
| `/presence` | 在宅状態 | Bearerトークン |

## 設定の編集

- **バス時刻表・祝日・ごみ収集ルール**は `config.js` だけを編集する。
  - 祝日リストは2030年分まで収録済み。2031年以降は追加が必要。
  - バスは都バス東43「宮城都営住宅前 → 田端駅前」、平日／土曜／休日の3ダイヤ。
- **トークン等の接続設定**は、ダッシュボードを `?setup=1` 付きで開くと入力できる（端末のローカル保存＋Cookieに保持）。

## デバッグ

- `?mode=morning` / `?mode=night` / `?mode=always` で表示モードを強制できる。
- `?time=HH:MM` で時刻を固定して表示を確認できる。
- ローカルで `index.html` をファイルとして開くと、自動で朝モードのプレビューになる。

## デプロイ

`main` ブランチへ push すると GitHub Pages に自動で公開される。

## 障害時の表示

- 天気：取得失敗が続く間は前回データを表示。データがない状態で3回続けて失敗したら「天気取得失敗」と表示し、30秒ごとに再接続を続ける。
- 運行情報・カレンダー：取得に失敗したら「取得エラー」と表示する。
